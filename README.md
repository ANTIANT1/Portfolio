# 🎨 Личное Портфолио

Добро пожаловать в мой workspace! Здесь собраны все мои проекты и достижения.

## 📋 О проекте

Это персональное портфолио, созданное для демонстрации моих проектов, навыков и профессионального опыта. Workspace организован таким образом, чтобы легко добавлять новые проекты и поддерживать актуальность информации.

## 🏗️ Структура проекта

```
PERSONAL/
├── .github/
│   └── copilot-instructions.md    # Инструкции для Copilot
├── assets/
│   ├── images/                     # Изображения
│   └── documents/                  # Документы (CV, сертификаты)
├── css/
│   └── style.css                   # Основные стили
├── js/
│   └── main.js                     # Главный JavaScript файл
├── projects/
│   ├── README.md                   # Информация о проектах
│   └── PROJECT_TEMPLATE.md         # Шаблон для новых проектов
├── index.html                      # Главная страница портфолио
└── README.md                       # Этот файл
```

## 🚀 Быстрый старт

1. Откройте `index.html` в браузере для просмотра портфолио
2. Используйте Live Server в VS Code для локальной разработки
3. Добавляйте новые проекты в папку `projects/`

## 📁 Добавление нового проекта

1. Создайте новую папку в `projects/` с названием проекта
2. Скопируйте `PROJECT_TEMPLATE.md` в новую папку как `README.md`
3. Заполните информацию о проекте
4. Обновите `index.html` для отображения проекта на главной странице
