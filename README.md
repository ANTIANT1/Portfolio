# 🎨 Личное Портфолио

Добро пожаловать в мой workspace! Здесь собраны мои проекты, навыки и профессиональное позиционирование как **Full-Stack Product Engineer** с фокусом на AI-интеграцию, автоматизацию и цифровые продукты.

## 📋 О проекте

Это персональное портфолио для демонстрации продуктовых и инженерных проектов: web-платформ, AI-инструментов, realtime-приложений, образовательных систем, игровых систем и автоматизации.

## 🧭 Позиционирование

**Основная роль:** Full-Stack Product Engineer  
**Фокус:** AI Integration · Automation · Web Platforms · Game Systems · Realtime Apps

Вместо узкого позиционирования как DevOps/System Architect, портфолио теперь должно показывать более широкую роль: разработчик, который может довести продукт от идеи до рабочего MVP — frontend, backend, API, база данных, интеграции, автоматизация и продуктовая логика.

## 🚀 Быстрый старт

1. Откройте `index.html` в браузере для просмотра портфолио
2. Используйте Live Server в VS Code для локальной разработки
3. Добавляйте новые проекты в папку `projects/`

## 📁 Добавление нового проекта

1. Создайте новую папку в `projects/` с названием проекта
2. Скопируйте `PROJECT_TEMPLATE.md` в новую папку как `README.md`
3. Заполните информацию о проекте
4. Обновите `index.html` для отображения проекта на главной странице
5. Обновите переводы в `js/main.js`, если проект должен отображаться на EN/DE/RU
