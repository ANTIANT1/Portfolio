# 🖼️ NRW ART - Онлайн-галерея для художников

> **Статус:** Learning / Pet Project | **Дата:** 2025 | **Прогресс:** 60%

## 📖 Описание

NRW ART — учебный full-stack проект. Онлайн-платформа для начинающих художников NRW: выставление и продажа работ, поиск, фильтры, корзина и оформление заказа с комиссией 15%.

## 🛠 Технологический стек

- **Frontend:** Next.js 14 (App Router) + Tailwind CSS
- **Backend:** Express.js + MongoDB (Mongoose)
- **Хранение изображений:** Cloudinary
- **Платежи:** Stripe, PayPal
- **Архитектура:** Monorepo (npm workspaces)

## 📁 Структура

```
NRWART/
├── apps/
│   ├── web/    # Next.js фронтенд (порт 3000)
│   └── api/    # Express API (порт 4000)
└── package.json
```

## 🎯 Функционал

- Галерея работ с фильтрацией и поиском
- Профили художников
- Корзина и оформление заказа
- Комиссия платформы (настраивается через ENV)
- JWT авторизация

## 📝 Заметки

Проект создан для изучения full-stack разработки на связке Next.js + Express + MongoDB. Не production-ready, но демонстрирует понимание e-commerce архитектуры и работы с платёжными системами.
